03Hash 路由：地址如何决定页面

路由只处理地址中的 # 片段，例如 #/todolist。导航链接改变 Hash，路由监听器收到变化后重新渲染。

HashpagetitlefixedTag
#/home首页null
#/todolistitemsTODOLISTTODOLIST
#/imaginationitemsIMAGINATIONIMAGINATION
#/totalitemsTOTALnull

resolverRoute() · 解析

raw ← 去掉 Hash 开头的 #
若 raw 为空：raw ← 默认路径 /
path ← 若缺少开头的 /，则补上
config ← ROUTES[path]

若找不到 config：
    返回 { path: /,
           config: 首页配置,
           unknown: true }
否则：
    返回 { path, config, unknown: false }

startRouter(onRoute) · 分发

定义 handle()：
    route ← resolverRoute()
    若 route.unknown：
        replaceState 将当前 Hash 改为 #/
        route ← 再次解析路由
    onRoute(route)

监听 hashchange → handle
立即执行 handle()
返回一个移除该监听器的函数
首次启动 / hashchange
↓
解析 Hash，补全路径前缀
↓
路由表中有该路径？
是 ↓
将路由交给 render
否 ↓
替换当前地址为 #/
重新解析 → render 首页

navigate(path) · 程序化跳转

规范化路径：确保以 / 开头
目标 Hash ← # + 路径
若目标与当前 Hash 相同：直接返回
否则：设置 window.location.hash
后续由 hashchange 触发渲染
当前页面使用普通链接导航，尚未调用 navigate()。未知地址使用 replaceState 替换当前历史记录，不新增一次首页跳转记录；随后代码主动重新解析并渲染。

05点击：通过父节点统一处理

点击监听器绑定在持久存在的 #app 上。子页面每次重新生成后，按钮仍可通过事件冒泡触发这一个监听器。

收到 app 内的点击事件：
    若 event.target 不是 Element：结束
    trigger ← 从目标向上寻找 [data-action]
    若没有匹配元素：结束

    若 trigger.dataset.action 为 add-note：
        alert「记录功能建设中...」
    其他 action：不处理
用户点击按钮或按钮内部元素
↓
事件冒泡至 #app
↓
找到 add-note 动作？
是 ↓
显示提示弹窗
保留当前页面
否 ↓
不执行自定义操作

导航链接没有 data-action，委托处理器不拦截默认点击行为；浏览器更新 Hash 后交由路由处理。当前没有表单、创建请求或数据保存。

06常量与配置：哪些已使用，哪些待接入

常量当前值 / 含义本阶段使用情况
TAG / TAG_LABELSTODOLIST → 待办；IMAGINATION → 想法TAG 用于路由固定分类；中文标签尚未展示。
STATUS / STATUS_LABELSCREATE → 待开始；RUNNING → 进行中；DONE → 已完成；CANCEL → 已取消；FAILED → 已失败已定义，尚无状态控件。

REQUEST_TIMEOUT10000 毫秒仅配置值，尚无超时处理实现。

config.js 的注释描述同源 /api 代理，而当前 API_BASE 是固定的本地绝对地址。该常量不会自动建立代理；本阶段没有导入此模块，也没有调用后端，因此两者暂未参与页面运行。

枚举、标签、路由和导航容器使用 Object.freeze。它是浅冻结，不会递归冻结 ROUTES 中的子配置或 NAV_ITEMS 中的对象。

阅读代码时的注意点

  • 空 Hash 使用首页，但不会强制将地址改为 #/；#todolist 可解析为 /todolist。
  • 路径精确匹配，未处理尾斜杠、大小写转换或 Hash 内的查询参数；未命中的地址会回首页。
  • 浏览器前进 / 后退引起 Hash 变化时，会再次渲染并滚动到顶部。
  • 页面以 ES Module 组织，应通过 HTTP 静态服务访问；直接双击 file:// 文件可能受到浏览器模块加载限制。
  • 没有加载动画、网络请求、真实列表、编辑删除或持久化实现。本页描述的是当前占位阶段。
